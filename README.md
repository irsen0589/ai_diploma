# 🎓 Дипломный проект  
## AI-ассистент (нейро-аниматор) для интерактивных игр с детьми

---

## 📌 Тема проекта  
Разработка AI-ассистента (нейро-аниматора) для генерации интерактивных развивающих игр для детей дошкольного возраста (3–6 лет) с использованием подхода Retrieval-Augmented Generation (RAG).

---

## 📊 Предпосылки  

В современном мире родители часто сталкиваются с проблемой нехватки идей для развивающих и вовлекающих игр с детьми.  

Существующие решения, как правило:
- предлагают статические списки игр;
- не адаптируются под возраст и интересы ребёнка;
- не поддерживают интерактивный формат.

Данный проект направлен на создание интеллектуального ассистента, который:
- генерирует персонализированные игровые сценарии;
- ведёт диалог с пользователем;
- адаптирует сценарий в процессе игры.

---

## 🎯 Описание задачи  

Разработать AI-систему, которая:

- принимает параметры:
  - возраст ребёнка,
  - интересы,
  - длительность игры;

- подбирает релевантные сценарии;

- генерирует пошаговые интерактивные игры;

- поддерживает диалог с пользователем (родителем);

- добавляет обучающие элементы (опционно войдет в проект при условии наличия времени):
  - квизы,
  - факты,
  - задания.

**Ключевая цель:**  
создание интерактивного игрового сценария, а не просто текстового ответа.

---

## ⚙️ Архитектура решения  

Проект будет реализован на основе RAG-подхода и включает следующие этапы:

### 1. Формирование базы знаний
Структурированные данные:
- игровые сценарии  
- педагогические методики  
- обучающие факты  
- квизы  

---

### 2. Предобработка данных
- разбиение данных на чанки (chunking)  
- генерация эмбеддингов  
- построение векторного индекса  

---

### 3. Retrieval (поиск)
- поиск релевантных данных по запросу пользователя  

---

### 4. Генерация (LLM)
- формирование сценария игры  
- добавление интерактивных элементов  
- поддержание диалога  

---

### 5. Fallback-логика
Если релевантные данные не найдены:
- система генерирует сценарий самостоятельно  

---

### 6. Multi-step логика
- шаг 1: анализ запроса пользователя  
- шаг 2: генерация игрового сценария  

---

### 7. Production-интеграция
- веб-приложение (Streamlit / FastAPI)  
или  
- Telegram-бот  

---

## 🗄 База знаний  

База знаний формируется на основе:

- открытых источников (статьи, сайты с играми для детей);  
- педагогических методик развития (логика, внимание, моторика);  
- образовательных материалов (факты, задания, квизы).  

---

### 📊 Структура данных

Каждый элемент базы включает:

- `type` — тип (game / fact / quiz / method)  
- `age` — возраст  
- `skill` — развиваемый навык  
- `topic` — тема  
- `content` — описание  
- `extra` — дополнительные параметры  

---

### 📈 Объём данных
- начальный: 50–100 элементов  
- с возможностью дальнейшего расширения  

---

## 🧠 Используемые технологии

- LLM (gpt-4o-mini или аналог)  
- Embeddings (OpenAI / HuggingFace модели)  
- Векторный поиск (FAISS / аналоги)  
- Python (pandas, numpy)  

---

## 🔬 Исследовательская часть

В рамках проекта планируется:

- сравнение методов chunking  
- сравнение моделей эмбеддингов  
- анализ влияния prompt engineering  
- настройка параметров генерации (temperature и др.)  

---

## 🚀 Результат проекта

AI-ассистент, который:
- генерирует персонализированные игры;  
- ведёт интерактивный диалог;  
- обучает через игру;  
- адаптируется под пользователя.  

---

## 💡 Ценность проекта

- практическое применение (родители и дети)  
- использование современных AI-подходов  
- демонстрация навыков работы с RAG-системами  
- реализация полноценного AI-продукта
