# 🎓 Дипломный проект  
## AI-ассистент (нейро-аниматор) для интерактивных игр с детьми

---

## 📌 Тема проекта  
Разработка AI-ассистента в формате Telegram-бота для генерации интерактивных развивающих игр для детей дошкольного возраста (3–6 лет) с использованием подхода Retrieval-Augmented Generation (RAG).

---

## 📊 Предпосылки  

Родители часто сталкиваются с нехваткой идей для развивающих игр с детьми.  
Существующие решения не учитывают индивидуальные особенности ребёнка и не поддерживают интерактивный формат.

Проект направлен на создание интеллектуального ассистента, который:
- генерирует персонализированные игровые сценарии;
- ведёт диалог;
- адаптируется в процессе взаимодействия.

---

## 🎯 Описание задачи  

Разработать систему, которая:

- принимает параметры:
  - возраст ребёнка,
  - интересы,
  - длительность игры;

- подбирает релевантные сценарии;
- генерирует пошаговые интерактивные игры;
- поддерживает диалог с пользователем;
- адаптирует сложность и структуру сценария.

**Цель:** создание интерактивного игрового процесса, а не статичного ответа.

---

## ⚙️ Архитектура решения  

Проект реализуется на основе RAG и включает:

### 1. База знаний
- игровые сценарии  
- педагогические методики  
- обучающие материалы  

---

### 2. Предобработка
- chunking  
- генерация эмбеддингов  
- индексирование (FAISS)  

---

### 3. Retrieval
- поиск релевантных данных по запросу  

---

### 4. Multi-step логика (LLM)

#### Шаг 1 — Анализ запроса  
- извлечение параметров пользователя  
- структурирование запроса  

#### Шаг 2 — Генерация  
- использование контекста из RAG  
- формирование сценария  
- генерация интерактивного ответа  

---

### 5. Production
Система реализуется в формате Telegram-бота:
- обработка пользовательских запросов  
- ведение диалога  
- генерация ответов в реальном времени  

---

## 🧠 Расширенная логика (Core AI)

### Memory
- хранение истории диалога  
- сохранение контекста взаимодействия  

Позволяет:
- избегать повторений  
- продолжать сценарии  
- поддерживать связный диалог  

---

### User Profile
- возраст  
- интересы  
- уровень сложности  

Позволяет:
- персонализировать сценарии  
- фильтровать данные  
- адаптировать стиль взаимодействия  

---

### Adaptive Difficulty
- динамическое изменение сложности  

Позволяет:
- усложнять задания при успешном выполнении  
- упрощать при затруднениях  

---

### Story Engine
- объединение игр в последовательные сценарии  

Позволяет:
- удерживать внимание  
- формировать сюжетное взаимодействие  

---

### Hybrid Search
- embeddings (семантический поиск)  
- BM25 (поиск по ключевым словам)  

Позволяет:
- повысить точность retrieval  
- учитывать как смысл, так и точные совпадения  

---

### Fallback-логика
- генерация сценария при отсутствии данных  
- использование профиля и контекста  

---

## 🗄 База знаний  

Формируется на основе:

- открытых источников  
- образовательных материалов  
- методик развития  

---

### Структура данных

- `type` — тип  
- `age` — возраст  
- `skill` — навык  
- `topic` — тема  
- `content` — описание  
- `extra` — дополнительные параметры  

---

### Объём
- 50–100 элементов с возможностью расширения  

---

## 🧠 Технологии

- LLM (gpt-4o-mini)  
- Embeddings (OpenAI / HuggingFace)  
- FAISS (векторный поиск)  
- Telegram Bot API  
- Python
